# hospital-db
## **Database System Assignment HCMUT**

Database design from given data requirements of Hospital management system.
* Conceptual design: Design EERD diagram (assignment 1)
* Logical design: Perform mapping from EERD to relational database schema (assignment 1)
* Physical design: Create physical database and implement triggers, functions for some business operations. Build a simple web application to demosntrate the solution. Apply indexing to improve retrieval performance and solve a use case of database security.  (assignment 2)
